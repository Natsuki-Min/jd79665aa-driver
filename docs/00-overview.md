# 00 · 控制器如何把图像变成画面

JD79665AA 是电子纸控制器：MCU 经 SPI 把图像交给它，它再按一套波形驱动面板。电子纸的最终颜色与驱动的方向、持续时间和此前的图像历史有关，因此“数据发对了”和“颜色达到目标了”是两个需要分别观察的环节。

本项目研究的硬件是 SE0398NZ07A1 四色面板，控制器按 JD79665AA / A1 实物进行分析。下面先说明各部分负责什么，再解释仓库中的研究路线。

## 1. 图像与波形是两份数据

一次显示可以分成三件事：

```text
MCU（Pico 或其他主机）
    │
    ├─ 0x10 + 图像字节 ──→ 图像 RAM：每个像素一个 2bit 类别
    │
    └─ 配置波形来源 ─────→ 内置原厂表，或 0x20 写入的自定义表
                                      │
                          0x12 / DRF：开始执行
                                      │
                    按像素类别选择对应的电压时序
                                      │
                               面板颜色发生变化
```

**图像 RAM**回答“这个位置属于哪一类”。在原厂四色模式中，四个类别对应黑、白、黄、红，所以写入 `00` 可以理解为请求黑色。

**LUT（波形表）**回答“这一类像素要经历什么驱动”。例如，某条自定义路径可以让类别 `01` 接正向电平三个扫描，再停止该路径；另一类则接负向电平。此时类别代表的是驱动动作，显示颜色取决于动作和像素原来的状态。

这也解释了两个都写作“2bit”的概念：图像中的 2bit 用来**选择路径**，波形状态中的 2bit 用来**选择电平**。具体格式见 [图像数据](01-panel-and-wiring.md)与 [R20 状态](04-lut.md)。

## 2. MTP、运行时 LUT 与 MCU 程序

MTP 是控制器内保存出厂数据的非易失存储区，里面包含压缩的波形资料和设置。R92 用于读出本项目的 MTP 样本；[第五章](05-mtp.md)说明怎样从样本中解出状态表。

R20 则是写入运行时自定义波形的接口。它接收编码后的波形字节，实测写地址以 2048 B 为周期回绕。修改波形、改变像素驱动时序，可以通过这个接口进行。

MCU 上的程序负责组织这些 SPI 命令、准备图像和等待控制器完成。Pico 是本仓库的参考实现；换用其他 MCU 后，图像、波形与命令之间的关系相同。

另外，选择“原厂 LUT”不一定立即恢复原厂运行内容：实验中，写入 R20 的标记在切回原厂模式后仍然影响刷新，而复位、正常初始化、上电的组合能恢复原厂时序。这一现象及其对对照实验的意义见 [实验一](06-refresh-experiments.md#1-切回原厂模式为什么没有恢复原厂刷新)。

## 3. 扫描、刷新与视频帧

**一次扫描**是波形的时间单位：电平码维持若干次扫描，就形成一个相位。PLL 设置影响扫描周期，例如标称 120 Hz 时每次扫描约 8.3 ms，实际周期可用 BUSY 或供电轨跳变测得。

**一次 DRF（Display Refresh）**是一次 `0x12` 命令。控制器在这次刷新中执行整套相关时序，可能只有几个扫描，也可能有数百个。R20 状态里的 A–F、G、RA、RB 决定这些扫描如何组合。

**一张视频帧**是主机要呈现的一张图。它可能触发一次 DRF，也可能因为补驱动、清理或数据未变而触发多次或零次。端到端帧率还包含图像传输和主机调度开销。因此，PLL 的“120 Hz”对应扫描时钟，不等于视频 120 fps。

## 4. 六路波形如何分工

解出的表有六条时序路径，本文命名为 H0–H5。H1–H4 分别供四种图像像素码选择；H0 与公共电极 VCOM 有关；H5 控制已观察到的 source 供电模式；source 指向像素列输出驱动电压的电路。每一路都有自己的状态序列，各路在同一次刷新中配合执行。

每个状态占 11 B：六个相位 A–F 的电平和持续扫描数，加上重复控制。可以先把它理解为一小段程序：重复执行 A→B→C，再重复执行 D→E→F，然后进入下一状态。[第四章](04-lut.md)给出完整字段表、编码函数和算例。

## 5. 研究是怎样推进的

首先用原厂波形建立四色显示基线，再用 R93 回读图像 RAM，区分“图像/地址写错”和“波形没有达到目标颜色”。R83 窗口的 X 镜像关系也是通过给不同窗口写不同标记、再回读实际位置得到的。

接下来研究 R20：先用已知短序列定位写地址周期，再逐位改变时长字段，看 BUSY 增量；同时观察 VSL（板上的负压供电轨）何时切换，以确认相位与重复结构。这一步得到字节编码和状态执行模型。

有了模型后，研究分成两条路线。一条是设计短波形，探索帧率、黑白端点和残影的取舍；另一条是恢复原厂表的字段，把原厂长波形当作参照。后者通过逐字段修改、比较计时差，得到了一组实测代表值及可辨识位。

最后，从 MTP 样本识别出 LZ 流。解压后按 R20 字节逆映射得到两张状态表，其中第二张与此前实测的可辨识位一致。这样，文件解码和硬件计时两条来源可以互相核对，而不必只靠“字节看起来像表”判断格式。

## 6. 各种测量回答什么问题

| 观察方式 | 主要用途 | 解释数值时的条件 |
| --- | --- | --- |
| R93 图像 RAM 回读 | 检查数据、坐标、打包方式 | 回读内容与可见颜色分别检查 |
| BUSY 低电平时长 | 判断刷新是否完成、比较扫描时序 | 多路并行时，总时长可能被最长一路遮住 |
| VSL/VCOM 等测试点 | 观察电源模式或公共电极的切换时刻 | ADC 原始码、板端电压与像素电极电压各有不同含义 |
| 固定曝光与白平衡的相机 | 比较亮暗、偏色、残影与历史差异 | 使用同次参考；本仓库的相机数值为相对量 |

如果目的是移植显示，从下一章开始即可；如果目的是继续研究快刷，第六章保留了完整的假设与对照过程。
