# 01 · 面板、接线与图像格式

## 1. 这是什么屏

| 项目 | 值 |
| --- | --- |
| 面板 | SE0398NZ07A1 |
| 控制器 | JD79665AA / A1（按实物研究，不按公开型号猜） |
| 物理分辨率 | 800 × 600 |
| 可见分辨率 | 768 × 552 |
| 颜色 | 4 色，2 bit/pixel |
| 可见区起点 | 物理坐标 (32, 0) |

| 一行 | 800 × 2 bit = **200 B** |

```text
物理 800 × 600
+------------------------------------------+
| 32 px 边距 |        可见 768 × 552        |
|   (白)     |  实际显示内容从这里开始       |
+------------------------------------------+

+------------------------------------------+
```

驱动里 `EPD_FRAME_WIDTH=800`、`EPD_FRAME_HEIGHT=600`、`EPD_FRAME_X_OFFSET=32`。画像素时把可见 x 加 32，再按 2bpp 打包。

## 2. 接线

| EPD | Pico | 说明 |
| --- | --- | --- |
| DIN | GP3 | SPI0 TX，数据 |
| CLK | GP2 | SPI0 SCK |
| CS | GP5 | 手动片选，低有效 |
| DC | GP6 | 低=命令，高=数据 |
| RST | GP7 | 低复位 |
| BUSY | GP8 | 输入；低=忙，高=空闲 |
| GND | GND | 必须共地 |

供电沿用原 PCB 的稳定 3.3 V 和 boost 电路，**不要**用 Pico 的 3V3 直接给面板高压部分供电。逻辑电平是 3.3 V。

实验里 GP26 接过 VSL 测量分压网络；那只是测量，不是显示必需。基础驱动不碰 GP26。

## 3. SPI 时序

- SPI0，mode 0（CPOL=0, CPHA=0），8 bit，MSB first。
- 没有 MISO。命令/数据都从 DIN 进。
- 正常全刷请求 **1 MHz**；历史实测分频后约 992 kHz。
- 高速实验里用过 8 MHz（实际约 7.8125 MHz）传小窗口；**基础驱动不用**，也不建议第一次上手就上高速。
- 每个命令是一个独立 CS 事务，DC=0；参数是另一个独立 CS 事务，DC=1。
- `0x10`（DTM）之后，整帧数据保持 CS 低，不逐行重设窗口。

驱动里的 `epd_cmd()` / `epd_data()` 就是这两类事务；`spi_payload()` 负责拉低 CS、发完、拉高，并等 SPI 真正排空后再抬 CS。

## 4. 图像数据格式

### 4.1 颜色码

原厂图像码（未加载自定义 LUT 时）：

| 2 bit 值 | 颜色 |
| ---: | --- |
| `00` | 黑 |
| `01` | 白 |
| `10` | 黄 |
| `11` | 红 |

每个字节装 4 个像素，**左边的像素在 bits 7:6**，然后 5:4、3:2、1:0。

例：一个字节 `0x1B` = `00 01 10 11` = 黑、白、黄、红。

### 4.2 行序与边距

- 线性行序：第 0 行在最前，每行 200 B。
- 可见区 x 从 32 开始；所以可见 x=0 对应帧内 x=32。
- 边距填白，打包值是 `0x55`（四个 `01`）。
- 整帧 120000 B；不要只发 768×552 的 105984 B，除非你明确改了窗口和几何。

### 4.3 一帧怎么组织

```c
/* 可见坐标 (x,y) 的 2bpp 打包 */
x += 32;
size_t index = y * 200 + x / 4;
unsigned shift = 6 - 2 * (x & 3);
frame[index] = (frame[index] & ~(3u << shift)) | (color << shift);
```

这段就是 `driver/src/main.c` 里的 `set_visible_pixel()`。

## 5. 哪些东西不在基础驱动里

- **R93 图像 RAM 回读**：实验里用单线读法（GP3 释放成输入、GP2 位操作）读过 120000 B，和发送内容零差异。基础驱动没有实现；它不影响正常显示。
- **R92 MTP 回读**：同理，MTP 是只读研究，不放进运行驱动。
- **R83 局刷**：有单独的窗口 API，见 [03-image-and-window.md](03-image-and-window.md)。
- **R20 自定义波形**：见 [04-lut.md](04-lut.md)。
- **相机/电压测量**：属于实验装置，不是屏能亮的前提。
