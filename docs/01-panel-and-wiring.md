# 01 · 面板、接线与图像格式

## 1. 这是什么屏

| 项目 | 值 |
| --- | --- |
| 面板 | SE0398NZ07A1 |
| 控制器 | JD79665AA / A1（本项目实物与驱动对应） |
| 物理分辨率 | 800 × 600 |
| 可见分辨率 | 768 × 552 |
| 颜色 | 4 色，2 bit/pixel |
| 可见区起点 | 物理坐标 (32, 0) |
| 一帧 | 800 × 600 × 2 bit = **120000 B** |
| 一行 | 800 × 2 bit = **200 B** |

物理帧比可见区宽 32 像素：可见区在物理坐标 x=32..799，左边空 32 像素，右边贴边。可见区 y=0..551，底部另有 48 行不可见区；可见坐标的 Y 起点没有偏移。

```text
物理 800 × 600
+------------------------------------------+
| 32 px 边距 |        可见 768 × 552        |
|   (白)     |  实际显示内容从这里开始       |
+------------------------------------------+
|          底部 48 行不可见区（白）          |
+------------------------------------------+
```

驱动里 `EPD_FRAME_WIDTH=800`、`EPD_FRAME_HEIGHT=600`、`EPD_FRAME_X_OFFSET=32`。画像素时把可见 x 加 32，再按 2bpp 打包。

## 2. 接线

| EPD | Pico | 说明 |
| --- | --- | --- |
| DIN | GP3 | SPI0 TX，数据 |
| CLK | GP2 | SPI0 SCK |
| CS | GP5 | 手动片选，低有效 |
| DC | GP6 | 低=命令，高=数据 |
| RST | GP7 | 低复位 |
| BUSY | GP8 | 输入；低=忙，高=空闲 |
| GND | GND | 必须共地 |

这里连接的是带供电/升压电路的原面板 PCB，SPI 逻辑电平为 3.3 V。面板所需正负高压由 PCB 的升压电路产生；Pico 提供逻辑接口。裸面板与带驱动 PCB 的模块需要的供电接口不同，移植时应按实际板卡连接。

VSL 是 PCB 上的负压供电轨，研究中通过额外分压与 ADC 观察其切换时刻；正常显示的接线表中没有这条测量连接。

## 3. SPI 时序

- SPI0，mode 0（CPOL=0, CPHA=0），8 bit，MSB first。
- 没有 MISO。命令/数据都从 DIN 进。
- 正常全刷请求 **1 MHz**；历史实测分频后约 992 kHz。
- 另有小窗口传输实验使用请求 8 MHz、实际约 7.8125 MHz；最小驱动配置为上述 1 MHz。
- 每个命令是一个独立 CS 事务，DC=0；参数是另一个独立 CS 事务，DC=1。
- `0x10`（DTM）之后，整帧数据保持 CS 低，不逐行重设窗口。

驱动里的 `epd_cmd()` / `epd_data()` 就是这两类事务；`spi_payload()` 负责拉低 CS、发完、拉高，并等 SPI 真正排空后再抬 CS。

## 4. 图像数据格式

### 4.1 颜色码

原厂图像码（未加载自定义 LUT 时）：

| 2 bit 值 | 颜色 |
| ---: | --- |
| `00` | 黑 |
| `01` | 白 |
| `10` | 黄 |
| `11` | 红 |

每个字节装 4 个像素，**左边的像素在 bits 7:6**，然后 5:4、3:2、1:0。

例：一个字节 `0x1B` = `00 01 10 11` = 黑、白、黄、红。

### 4.2 行序与边距

- 线性行序：第 0 行在最前，每行 200 B。
- 可见区 x 从 32 开始；所以可见 x=0 对应帧内 x=32。
- 边距填白，打包值是 `0x55`（四个 `01`）。
- 当前全窗配置接收物理帧 120000 B。768×552 对应的 105984 B 只包含可见区域，不能在相同全窗配置下替代物理帧。窗口更新的数据长度由窗口宽高决定。

### 4.3 一帧怎么组织

```c
/* 可见坐标 (x,y) 的 2bpp 打包 */
x += 32;
size_t index = y * 200 + x / 4;
unsigned shift = 6 - 2 * (x & 3);
frame[index] = (frame[index] & ~(3u << shift)) | (color << shift);
```

这段就是 `driver/src/main.c` 里的 `set_visible_pixel()`。

## 5. 从普通显示到进一步分析

最小驱动实现复位、初始化、全帧/窗口写入与刷新。R83 窗口的作用和坐标换算见 [第三章](03-image-and-window.md)。

检查 SPI 图像链路时，可利用 R93 读回图像 RAM。研究中使用同一 DIN 线半双工读取：发送后将数据 GPIO 释放为输入，并用时钟 GPIO 取样。120000 B 全帧回读与发送数据零差异，帮助把地址问题与光学响应分开；该读回接口尚未加入本驱动。

研究波形则从 R20 开始，见 [第四章](04-lut.md)。R92 读取的 MTP 提供出厂数据样本，其解码工具已随仓库提供，见 [第五章](05-mtp.md)。
