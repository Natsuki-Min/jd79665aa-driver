# 04 · R20：编写像素的驱动时序

R20 是写入运行时波形表的命令。它让同一个图像像素码选择不同的驱动过程：例如，图像中的 `01` 可以选择一条正向驱动三扫描的路径，`10` 选择另一条负向路径。设计短波形时，工作重点就是这些路径的相位、电平和重复次数。

一套波形由六路状态序列组成，本文命名为 H0–H5。H1–H4 分别对应四种像素码，另两路处理公共电极与 source 供电模式。先理解这层分工，再看字节布局，会比从一串 R20 参数开始更容易移植。

## 1. 六路时序与一个状态

| 路径 | 观察到的作用 |
| --- | --- |
| H0 | 公共电极 VCOM；切换电平码时可见额外约 21 ms 开销 |
| H1 | 图像 RAM 像素码 `00` 选择的路径 |
| H2 | 图像 RAM 像素码 `01` 选择的路径 |
| H3 | 图像 RAM 像素码 `10` 选择的路径 |
| H4 | 图像 RAM 像素码 `11` 选择的路径 |
| H5 | source 供电的 Mode0/Mode1 选择；其他位作用仍待分析 |

每路包含连续的状态。一个状态最多描述六个相位 A–F，每个相位指定电平码和持续扫描数；RA、RB 分别控制前三相与后三相的重复，G 控制整个状态的重复。

```text
重复 G 次：
    重复 RA 次：A → B → C
    重复 RB 次：D → E → F
然后继续下一状态
```

各路在一次 DRF 中配合执行。某一路缩短后，总 BUSY 仍可能由另一条较长路径决定；测单路字段时需要让目标变化能超过其他路的时长下限，或用 VSL/VCOM 的局部跳变辅助判断。

## 2. 选择波形来源与写入

PSR（命令 `00`）第二参数的 bit 7 选择 LUT 来源。正常四色初始化使用 `4B 69`；置 bit 7 后的 `4B E9` 用于寄存器 LUT。实验还使用过 `4B F9`，其中增加了项目称为 VCMZ 的设置；它与 E9 的具体光学差异应作为独立变量比较。

```text
00 4B E9       选择寄存器 LUT
20 + payload  写入波形字节
12 00          执行一次刷新
```

这段描述 LUT 的选择、写入和执行关系。完整显示还包括初始化、供电配置、PLL、图像 RAM 写入和高压开关，见 [全刷流程](02-init-and-refresh.md)。

R20 写入从地址 0 开始，连续地址按 **2048 B** 回绕。短写只替换前缀，后面的旧内容保留，因此实验里常先生成完整的 2048 B 缓冲区，再一次发送。逻辑零的编码是 `FF`，可作为清空状态内容的底板；表头和有效状态随后按所需配置填入。

模式选择与内容恢复是两个动作。实测中，R20 标记在切回原厂模式、甚至 POF/PON 后仍会影响后续执行；复位、正常初始化、PON 的组合恢复了原厂时序。做波形前后对照时，这个行为会影响起始状态，详见 [生命周期实验](06-refresh-experiments.md#1-切回原厂模式为什么没有恢复原厂刷新)。

## 3. 表块的地址布局

从 MTP 解出的每张表块为 535 B：

```text
7 B 头部 + 6 路 × 8 状态 × 11 B = 535 B
```

| 路径 | 第一个状态的字节偏移 |
| --- | ---: |
| H0 | 7 |
| H1 | 95 |
| H2 | 183 |
| H3 | 271 |
| H4 | 359 |
| H5 | 447 |

通式是 `7 + 88*H + 11*K`，其中 H 为路径 0–5，K 为表块中的状态 0–7。535 B 描述识别出的表块，2048 B 描述实测写地址周期；它们回答不同问题。入口间距 88 B 是已知布局，物理存储是否分成独立 bank、八状态是否是硬件上限，尚未单独确定。

## 4. 11 B 状态的字段

下表中的值均为逻辑字节，经过下一节的映射才是 SPI 实际发送的字节。

| 相对偏移 | 字段 | 含义 |
| ---: | --- | --- |
| 0 | G | 外层重复；0 表示本路径在此终止 |
| 1 | ABC_levels | A/B/C 电平码分别位于 bits 7:6、5:4、3:2；低两位另行保留 |
| 2 | DEF_levels | D/E/F 的电平码，位位置同上 |
| 3 | A | A 相扫描数 |
| 4 | B | B 相扫描数 |
| 5 | C | C 相扫描数，计数模型使用低 7 bit |
| 6 | RA | ABC 子组重复 |
| 7 | D | D 相扫描数 |
| 8 | E | E 相扫描数 |
| 9 | F | F 相扫描数，计数模型使用低 7 bit |
| 10 | RB | DEF 子组重复 |

对已验证的非空状态，计划扫描数为：

```text
N = G * ((A+B+C)*RA + (D+E+F)*RB)
```

例：`G=3`，`A/B/C=2/3/4`、`RA=2`，`D/E/F=1/2/3`、`RB=3`，得到 `3*((2+3+4)*2+(1+2+3)*3)=108` 扫描。50 Hz 档实测约 2.219 s，与扫描周期及固定开销相符。工具对 C/F 取低 7 bit，另外报告高位；该高位的功能尚未解释。

G=0 的含义是终止后续执行。相反，G 非零但相位时长全零的空状态，实验中仍可消耗约一次扫描。生成器因此需要区分“终止路径”和“存在一个空状态”；后者不总符合上面的零乘法计数。

## 5. 逻辑字节如何变成 R20 wire 字节

字段的自然数值与 R20 接收的字节之间有固定的位重排和取反：

```text
逻辑 bit：0 1 2 3 4 5 6 7
线上 bit：4 7 6 1 0 3 2 5
wire = 0xFF XOR permute(logical)
```

| 逻辑值（十进制） | 0 | 1 | 2 | 4 | 8 | 16 | 32 | 64 | 128 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| wire（hex） | FF | EF | 7F | BF | FD | FE | F7 | FB | DF |

这个关系通过改变时长字段的单 bit、组合计数和供电轨相位位置得到。图像数据与普通寄存器参数仍按其各自格式发送；MTP 则先解压，解压结果才进入这层逆映射。

`host/lut_codec.py` 提供对应函数。从 `host/` 目录可运行：

```python
from lut_codec import encode_byte, decode_byte, pack_state, unpack_state

assert encode_byte(1) == 0xEF
assert decode_byte(0xFF) == 0
wire = pack_state(3, [0,1,2,0,1,2], [2,3,4,1,2,3], [2,3])
assert unpack_state(wire)["scheduled_scans"] == 108

# 演示把一个状态放到 H2 首槽；此处仅构造状态区域。
table = bytearray([0xFF] * 2048)
table[183:194] = wire
```

`pack_state()` 返回 wire 字节。上例省略了表头与其他路径配置，用于说明字段与位置；参考表的实际头部和所有状态可用 `python3 host/show_profile.py` 从仓库根目录查看。

## 6. 电平码、供电模式与显示颜色

像素路径中，2bit 电平码选择控制器的电压轨：

| 码 | 本文名称 | 控制器电压名 / PCB 丝印 | 实测驱动趋势 |
| ---: | --- | --- | --- |
| 00 | L00 | 接近零电压的设置 | 短时可近似保持，输出阻抗与长期行为未直接确定 |
| 01 | L01 | VSP / VSH1 | Mode0 强正档，白/黄向暗色变化 |
| 10 | L10 | VSN / VSL | 负档，黑变浅，色相受历史与剂量影响 |
| 11 | L11 | VSPL / VSH2 | 较弱正档，变暗较慢 |

Mode0、Mode1 是 H5 控制的供电模式。它们可以在一次 DRF 内切换，因此某个像素相位的电压还取决于同一时刻的 H5 状态。H5 的 2bit 码用于供电控制，其意义与像素路径中的电压选择不同。

颜色是整段驱动的结果。相同的负向扫描施加在原厂白、刚变黑、反复驱动过的像素上，可能得到不同浅色。研究中曾用带正负强弱差异的颗粒模型解释现象，但本资料不把颗粒净电荷或迁移率当作直接测量结果。[第六章](06-refresh-experiments.md)给出了区分这些历史的对照方法。

终止路径也只说明不再执行该路径后续相位；它与显式 L00 相位是不同的程序行为，终止后的电极状态还涉及输出电路。像素是否保持原色，可以用静止参照区和相邻活动区的实验来判断。

## 7. H1 首状态的特殊计数

H1 首槽与其他槽位的表现不同。100 Hz 对照中，头部字节 R20[6] 逻辑为零时，H1 首槽 A2 约 11.007 ms，只表现为一次扫描；该头字节为 1 时，A1/A2/A4/A8 分别约 11.002/21.194/41.588/82.368 ms，恢复了随扫描数增长的关系。

但只启用 C3、D3、E3 或 F3，且 A=B=0 时，H1 首槽仍约 11 ms；相同波形放到 H2 首槽约 31.4 ms，放到 H1 第二槽并计入一帧前缀约 41.6 ms。把 A 或 B 设为非零后，混合相位又按普通计数展开。

因此，头部非零值能改变部分首槽计数，却尚不能完整解释其机制。`02/03/04/08/10/20/40/80` 也产生已测 A2 恢复效果，说明逻辑 bit0 不是唯一必要条件。现有短波形曾采用把有效状态放到后槽，或用 H2/H3 承载黑白动作的办法，绕开首槽对计数分析的影响。

## 8. 原厂状态表与后续工作

`data/profile-01.logical.bin` 的头部为 `00 22 24 78 22 00 08`，六路各 742 扫描，与实测可辨识字段一致。它给出了真实文件中的表头和完整 level 字节，适合分析长波形如何安排正负相位。表块的提取过程、实测对照和未知容器字段见 [MTP 章节](05-mtp.md)。

继续构造完整执行配置时，仍需确定表块在运行空间中的装载、终止方式以及配套电压设置。头部其他字段、level 低两位和 C/F 高位也保留在样本中，供后续独立分析。
